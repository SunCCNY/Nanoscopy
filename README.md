# Nanoscopy-Lab
Projects for single molecule localization microscopy (SMLM) at Nanoscopy Laboratory 

# Folders

Each folder contains the MATLAB codes used in a published paper. A folder is named with the year of publication, journal, and keywords. 

# SMLM_Lib

Folder SMLM_Lib contains the Python library for SMLM. 

SMLM_Lib is built upon the universal model of frames [1, 2], the Markov chain model of fluorescence molecule photoactivation process [3, 4], and quality metrics [3, 5]. 

SMLM_Lib is used in our projects in SMLM. 

SMLM_Lib can also be broadly applied to modeling, theoretical anaysis, simulation, image reconstruction, performance benchmarking and evaluation in SMLM.
