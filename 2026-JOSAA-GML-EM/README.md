## Purpose


Preprint and the Python codes developed to generate the five figures used in the paper: 

[1] Y. Sun, "Asymptotic Efficiency of the Global Maximum-Likelihood Estimator in Multi-Emitter Localization Microscopy," (submitted to JOSA A, July 9, 2026). 

## Run codes

- Download SMLML_Lib from https://github.com/SunCCNY/Nanoscopy/tree/main/SMLM_Lib.

- Download the three drivers.

- Point the drivers to SMLM_Lib by adding the path of SMLM_Lib to the root. 

- Run the three drivers will generate the five figures in the paper.
