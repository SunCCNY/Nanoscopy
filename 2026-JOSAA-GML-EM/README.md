## Purpose

The Python codes are developed to generate the five figures used in the paper: 

[1] Y. Sun, "Asymptotic Efficiency of the Global Maximum-Likelihood Estimator in Multi-Emitter Localization Microscopy."

## Run codes

- Download SMLML_Lib from https://github.com/SunCCNY/Nanoscopy/tree/main/SMLM_Lib.

- Download the three drivers.

- Point the drivers to SMLM_Lib by adding the path of SMLM_Lib to the root. 

- Run the three drivers will generate the five figure in the paper.
